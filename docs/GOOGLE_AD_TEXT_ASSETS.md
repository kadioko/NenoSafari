# Google App Campaign Text Assets

> Reviewed against the Neno Safari 2.13.0 store promise on August 19, 2026.

Use these in the Google Ads App campaign asset setup.

Public listing: `https://play.google.com/store/apps/details?id=com.nenosafari`

## Limits

- Headlines: up to 5, maximum 30 characters each.
- Descriptions: up to 5, maximum 90 characters each.
- Each line should make sense on its own because Google can combine assets in different ways.
- Use all 5 headline slots and all 5 description slots to improve ad strength.

## Best Starting Combination

Start with all 5 headlines and all 5 descriptions. If Google asks for a primary angle, lead with:

- Headline: `Find Words, Learn Swahili`
- Description: `Find Kiswahili words, learn meanings, pronunciation, and example sentences.`

## Ad Strength Notes

- These assets cover different intent angles: language learning, word search, Tanzania, free play, and memory review.
- Do not duplicate the same phrase across every asset.
- Keep the campaign language targeting aligned with the English ad copy.
- Use the generated image assets in `assets/ad-campaign/`, but avoid superimposed "Download" or "Install" text on images.
