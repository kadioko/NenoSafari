## Full Description

Neno Safari is a fun Swahili vocabulary word search game inspired by Tanzania. Find hidden Kiswahili words in themed puzzles, learn their English meanings, hear pronunciation, and see simple example sentences you can use in daily life.

Explore words from Tanzanian food, cities, animals, greetings, family, markets, transport, weather, culture, and national life. Each puzzle helps beginners and intermediate learners build useful Swahili vocabulary while enjoying a simple, mobile-friendly game.

Features:

- Tanzania-themed word search puzzles
- Swahili-first interface with optional English support
- Learn Mode with meanings and example sentences
- Daily Tanzania Puzzle and streak tracking
- Saved words for revision
- Progress tracking by category
- Coins, badges, and rewards
- Offline-friendly play
- Accessibility settings for reduced motion and high contrast

Neno Safari is made for Swahili learners, Tanzanians, students, tourists, kids, and anyone interested in Tanzanian culture. The game is simple to start, educational, respectful, and proudly Tanzanian.

Find words. Learn Swahili. Enjoy the safari.
