## Decision Rules

- If people install but do not review, ask for more direct feedback before paid ads.
- If people click posts but installs are weak, refresh screenshots and the first two store description sentences.
- If reviews mention missing content, ship a content update before new features.
- If reviews mention confusion, improve onboarding or screenshots before adding more categories.
- If crashes or ANRs appear, pause promotion until fixed.
- If players repeatedly misunderstand Again, Hard, Got It, or due timing, improve review copy before changing the scheduling intervals.
